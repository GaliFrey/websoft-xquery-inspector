# Шаблон WebSoft и стендовые агенты

## Сборка и установка шаблона

`websoft/websoft-xquery-inspector.html` — сгенерированный поставочный файл. Его исходные
части находятся в `websoft/src/`; готовый файл не редактируют вручную.

```bash
node tools/build-template.js
node tools/build-template.js --check
```

Первая команда пересобирает шаблон, вторая только проверяет его актуальность. Для поставочного
файла зафиксированы UTF-8 BOM и окончания строк CRLF.

Для установки:

1. Создайте настраиваемый шаблон с кодом `websoft-xquery-inspector`.
2. Скопируйте в него `websoft/websoft-xquery-inspector.html` целиком, включая вставки `<% %>`.
3. Сохраните шаблон в UTF-8 с BOM.
4. На время разработки отключите `use_session_cache`.
5. Опубликуйте шаблон через маршрут портала и ограничьте доступ администраторами.

Это содержимое настраиваемого шаблона, а не файл для каталога xHttp.

## HTTP-интерфейс

GET возвращает HTML-фрагмент. POST-запрос через AJAX отправляет `action=inspect` и `xquery` на:

```text
/custom_web_template.html?object_code=websoft-xquery-inspector
```

Обработчик возвращает JSON без HTML-обёртки портала и сохраняет штатную проверку доступа к
шаблону. Длина XQuery ограничена 200000 символов: интерфейс проверяет строку до отправки,
серверный обработчик возвращает HTTP 413 до загрузки DLL, а `Inspector.Inspect()` повторяет ограничение.

## Интерфейс и данные

Интерфейс содержит редактор, блоки SQL, Count SQL и эффективного XQuery, таблицу параметров,
самодиагностику и исходный JSON. При включённом `SqlOffset` он предупреждает, что во время чтения
коллекции UniBridge может добавить сортировку и постраничную выборку (обычно по 400 записей), поэтому
реально выполняемый SQL может отличаться от показанного. Отдельные блоки можно копировать. Стили и
DOM-запросы ограничены контейнером `.xqi-root`, чтобы не затрагивать коробочную разметку портала.

Запросы и результаты не сохраняются в `localStorage`, не журналируются автоматически и не отправляются на
сторонние ресурсы. Копируемые данные могут быть чувствительными; обезличивание при копировании не
выполняется.

## Стендовые агенты

`websoft/xquery-inspector-compatibility-agent.js` выполняет обязательные проверки DLL внутри WebSoft HCM и пишет
обезличенные результаты в журнал `xquery_inspector_compatibility`.

`websoft/xquery-inspector-compatibility-agent-2.js` автоматизирует ручную часть протокола, выполняет два
тестовых `tools.xquery()` и пишет полный JSON в журнал `xquery_inspector_manual`. Его можно запускать только на изолированном
стенде.

Подробный порядок запуска и правила обновления статуса описаны в
[протоколе стендовой проверки](../compatibility/README.md#протокол-стендового-прогона).
